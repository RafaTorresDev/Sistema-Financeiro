# FINTRACK — Sistema Financeiro

Aplicação web para controle de finanças pessoais. Permite registrar entradas e saídas, visualizar o extrato e acompanhar o saldo total.

## Acesso

[sistema-financeiro-jade-tau.vercel.app](https://sistema-financeiro-jade-tau.vercel.app)

## Funcionalidades

- Adicionar transações (entrada ou saída)
- Visualizar extrato completo
- Calcular saldo total automaticamente
- Deletar transações

## Tecnologias

**Frontend**
- React + Vite

**Backend**
- Java 17 + Spring Boot

**Banco de dados**
- MySQL

**Deploy**
- Frontend: Vercel
- Backend + Banco: Railway
